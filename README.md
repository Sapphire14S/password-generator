# Password Generator

A simple and responsive password generator that creates secure passwords with customizable length and character options.

## Live Demo

https://github.com/Sapphire14S/password-generator/

## Features

* Generate random passwords instantly
* Adjustable password length
* Optional numbers and symbols
* Password strength indicator
* One-click copy to clipboard
* Responsive user interface

## Tech Stack

* HTML
* CSS
* JavaScript

## Installation

```bash
git clone https://github.com/Sapphire14S/password-generator.git
cd password-generator
```

Open `index.html` in your browser.
